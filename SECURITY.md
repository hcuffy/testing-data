# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

To report a vulnerability, open a [GitHub Security Advisory](https://github.com/hcuffy/testing-data/security/advisories/new) in this repository. You will receive a response within 7 days.

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a minimal proof-of-concept
- Affected versions

## Notes

`testing-data` generates synthetic random data for testing purposes. It does not make network requests, store credentials, or process real personal data. The attack surface is limited to the npm package supply chain.
